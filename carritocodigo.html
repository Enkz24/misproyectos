Proyecto de robótica · Carrito Autónomo 2WD

Robot Carrito Arduino | Arquitectura + Código Base

Propuesta técnica y de código para un robot móvil autónomo. Construido sobre un chasis de dos motores (2WD), utiliza un sensor ultrasónico para evitar obstáculos y un sistema de luces LED que reacciona a los eventos de navegación (avance, detección y maniobra evasiva).

Objetivo del sistema

Crear un vehículo capaz de navegar por su entorno sin intervención humana. El "cerebro" lee constantemente la distancia frente a él. Si el camino está libre, avanza encendiendo sus luces de marcha. Si detecta un obstáculo, se detiene, activa alertas visuales rojas y utiliza un servo para decidir su ruta de escape.

Hardware clave: Arduino Nano/Uno como controlador, HC-SR04 como sensor principal, L298N para la gestión de potencia a los motores y Micro Servo SG90 para visión periférica.

Componentes y Conexiones

  • Chasis acrílico con 2 motores DC (tracción diferencial).
  • Driver L298N conectado a pines PWM para control de velocidad.
  • Sensor Ultrasónico HC-SR04 montado sobre el servo SG90.
  • LEDs indicadores (Rojo = Peligro/Detenido, Blanco/Azul = Avanzando).
  • Batería independiente para motores y Arduino.

Configuración de Pines y Hardware

Definición de conexiones C++ / Arduino IDE 
#include <Servo.h>

// Sensor Ultrasónico
#define TRIG_PIN 9
#define ECHO_PIN 10

// Luces LED
#define LED_AVANCE 4
#define LED_ALERTA 5

// Motores (Driver L298N)
#define IN1 6  // Motor Izquierdo Adelante
#define IN2 7  // Motor Izquierdo Atrás
#define IN3 8  // Motor Derecho Adelante
#define IN4 11 // Motor Derecho Atrás

Servo servoMotor;

void setup() {
  pinMode(TRIG_PIN, OUTPUT);
  pinMode(ECHO_PIN, INPUT);
  pinMode(LED_AVANCE, OUTPUT);
  pinMode(LED_ALERTA, OUTPUT);
  
  pinMode(IN1, OUTPUT);
  pinMode(IN2, OUTPUT);
  pinMode(IN3, OUTPUT);
  pinMode(IN4, OUTPUT);
  
  servoMotor.attach(3);
  servoMotor.write(90); // Mirar al frente
  Serial.begin(9600);
}

Estructura del Hardware

El bloque de configuración establece qué pines del Arduino actuarán como salidas (motores, LEDs, Trig del sensor) y cuáles como entradas (Echo del sensor). El objeto Servo se inicializa a 90 grados para mirar hacia adelante.

Lógica de Detección y Luces

Bucle principal (Loop) Control Autónomo 
void loop() {
  long distancia = medirDistancia();
  
  // Umbral de peligro: 20 cm
  if (distancia > 0 && distancia < 20) {
    // Modo Alerta
    digitalWrite(LED_AVANCE, LOW);
    digitalWrite(LED_ALERTA, HIGH);
    detenerMotores();
    delay(500);
    
    // Evadir obstáculo
    retrocederUnPoco();
    buscarRutaLibre(); 
  } else {
    // Modo Seguro
    digitalWrite(LED_ALERTA, LOW);
    digitalWrite(LED_AVANCE, HIGH);
    avanzar();
  }
  delay(100);
}

long medirDistancia() {
  digitalWrite(TRIG_PIN, LOW);
  delayMicroseconds(2);
  digitalWrite(TRIG_PIN, HIGH);
  delayMicroseconds(10);
  digitalWrite(TRIG_PIN, LOW);
  long duracion = pulseIn(ECHO_PIN, HIGH);
  return duracion * 0.034 / 2; // Convertir a cm
}

Toma de Decisiones

El robot opera en un bucle infinito donde la función medirDistancia() lanza un pulso de sonido y calcula el tiempo que tarda en rebotar.

Si la distancia es menor a 20 cm, el flujo entra en Modo Alerta: apaga las luces de marcha, enciende los LEDs rojos, frena los motores y ejecuta la rutina de evasión. Si el camino está despejado, retoma su marcha normal.

Control de Tracción (Driver L298N)

Funciones de Movimiento Puente H 
void avanzar() {
  digitalWrite(IN1, HIGH);
  digitalWrite(IN2, LOW);
  digitalWrite(IN3, HIGH);
  digitalWrite(IN4, LOW);
}

void detenerMotores() {
  digitalWrite(IN1, LOW);
  digitalWrite(IN2, LOW);
  digitalWrite(IN3, LOW);
  digitalWrite(IN4, LOW);
}

void girarDerecha() {
  // Motor izquierdo avanza, derecho retrocede
  digitalWrite(IN1, HIGH);
  digitalWrite(IN2, LOW);
  digitalWrite(IN3, LOW);
  digitalWrite(IN4, HIGH);
  delay(400); // Tiempo de giro
  detenerMotores();
}

Movimiento Diferencial

Al usar un chasis 2WD, el carrito gira mediante tracción diferencial. Para avanzar, ambos motores giran en la misma dirección. Para detenerse, se corta la energía a todos los pines.

Para realizar un giro sobre su propio eje (ej. girar a la derecha), se invierte la polaridad de un motor respecto al otro gracias al Puente H integrado en el L298N.

Flujo de Evitación de Obstáculos

1
Exploración Constante

El sensor ultrasónico escanea el entorno frontal. El servo mantiene el sensor apuntando recto a 90 grados.

2
Marcha Segura

Motores activos en avance. Luces indicadoras blancas o azules encendidas mostrando que la ruta está despejada.

3
Detección y Freno

Objeto a menos de 20cm detectado. Los motores se bloquean, luz blanca se apaga y LED rojo parpadea o se mantiene fijo.

4
Maniobra Evasiva

El servo gira a 0° y 180° midiendo distancias laterales. El Arduino compara y gira el chasis hacia la ruta con más espacio.

Ventaja de la Modularidad

Aunque se puede escribir todo en un solo archivo, separar el código en múltiples pestañas (archivos .ino) dentro de la misma carpeta facilita encontrar errores y escalar el proyecto (por ejemplo, añadir control por Bluetooth más adelante sin ensuciar la lógica de evasión).
